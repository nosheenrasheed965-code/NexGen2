# Git practice checklist

- [ ] `git status` — check changes.
- [ ] `git branch --show-current` — check the current branch.
- [ ] `git remote -v` — check the configured remote.
- [ ] Make a small, meaningful change.
- [ ] `git diff` — review it.
- [ ] `git add <specific-files>` — stage only intended files.
- [ ] `git commit -m "Add Laravel Git learning demo"` — create a local commit.
- [ ] `git push` — push if authorized and configured.
- [ ] Practice `git pull` after a teammate or GitHub adds a harmless change.

Always check your current branch and team instructions before pushing to a shared repository.
